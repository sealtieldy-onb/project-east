- **Appearance and responsive layout:** The available Yab viewport was 1024×640 and displayed the dark appearance. Source defines `prefers-color-scheme` rules and responsive breakpoints, but light-mode switching and a mobile-width runtime check were unavailable through the allowed browser controls. No screenshot was retained.
